# Módulo de Matemáticas Básicas

Este es el primer módulo de mi repositorio de prácticas de Python. Aquí documento el proceso de resolución de operaciones matemáticas fundamentales utilizando scripts estructurados.

## Contenido
- **0_Matematicas.py**: Script que contiene ejercicios de:
    - Suma
    - Resta
    - Multiplicación
    - División

## Objetivos
- Aprender la sintaxis básica de Python.
- Implementar el uso de *f-strings* para un formateo de texto limpio.
- Desarrollar eficiencia en la resolución de procesos algorítmicos.
- Aplicar buenas prácticas de legibilidad y estructuración de código.

## Cómo ejecutar
Desde tu terminal, navega hasta la ubicación de esta carpeta y ejecuta:
```bash
python 0_Matematicas.py
