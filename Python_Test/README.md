# Módulo de Matemáticas Básicas

Este es el primer módulo de mi repositorio de prácticas de Python. Aquí documento el proceso de resolución de problemas matemáticos mediante scripts estructurados, utilizando variables, operaciones, resultados intermedios, porcentajes y estructuras condicionales.

## Contenido

* **`0_Matematicas/`**: Carpeta que contiene retos y ejercicios matemáticos progresivos, comenzando con operaciones básicas y avanzando hacia problemas que requieren mayor razonamiento lógico.

  * Operaciones aritméticas básicas.
  * Resolución de problemas matemáticos.
  * Operaciones encadenadas.
  * Porcentajes.
  * Aumentos y descuentos.
  * Estructuras condicionales `if`, `elif` y `else`.
  * Toma de decisiones basada en valores.

## Metodología

Los ejercicios se desarrollan siguiendo una estructura progresiva:

1. Identificar los datos del problema.
2. Asignar los datos a variables.
3. Determinar las operaciones necesarias.
4. Resolver el problema mediante pasos intermedios cuando sea necesario.
5. Utilizar estructuras condicionales para tomar decisiones.
6. Obtener el resultado final.
7. Mostrar los resultados mediante `print()` y *f-strings*.

## Objetivos

* Aprender y reforzar la sintaxis básica de Python.
* Comprender el uso de variables y asignaciones.
* Practicar operadores aritméticos y de comparación.
* Implementar el uso de *f-strings* para un formateo de texto limpio.
* Aprender a descomponer problemas en pasos lógicos.
* Resolver problemas matemáticos mediante código.
* Comprender y aplicar porcentajes, aumentos y descuentos.
* Introducir estructuras de control mediante `if`, `elif` y `else`.
* Desarrollar el razonamiento lógico y algorítmico.
* Aplicar buenas prácticas de legibilidad y estructuración de código.

## Cómo ejecutar

Desde la terminal, navega hasta la ubicación de la carpeta y ejecuta el archivo `.py` correspondiente.

Por ejemplo:

```bash
python archivo.py
```
